# PrismVista 3D (실시간 PBR 레이 트레이싱 & 3D 건축 시각화 렌더러)

**PrismVista 3D**는 [D5 Render](https://www.d5render.com/)의 핵심 실시간 렌더링, 태양광 및 날씨 대기 환경 시뮬레이션, PBR 머티리얼 편집, 3D 모델(OBJ) 로딩, 시네마틱 톤매핑 및 고화질 이미지 렌더링 내보내기 기능을 충실히 모사하여 개발된 독립형 3D 렌더러 소프트웨어입니다.

Windows 데스크톱 앱뿐만 아니라, **설치 없이 크롬, 엣지, 사파리 등 모든 웹 브라우저(PC/Mac/모바일/태블릿)에서 즉시 접속하여 사용할 수 있는 웹 렌더러**로 완전 지원됩니다.

---

## 🌐 웹(Web)에서 사용하기

PrismVista 3D는 외부 프레임워크나 서버 의존성이 전혀 없는 **순수 표준 WebGL 2.0 및 HTML5/ES6** 기반으로 제작되어 별도의 플러그인 없이 웹 브라우저에서 100% 동일한 고품질 3D 그래픽을 구동할 수 있습니다.

### 1. 내 컴퓨터/로컬 네트워크에서 웹으로 실행 (1-클릭 웹 서버)
1. 폴더 내의 **`start_web.bat`** (또는 **`start_web_server.exe`**)를 더블 클릭하여 실행합니다.
2. 내장 고속 웹 서버가 시작되며 기본 웹 브라우저가 자동으로 열립니다:
   * **로컬 접속 주소**: `http://localhost:8080/`
   * **모바일/태블릿/타 PC 접속**: 터미널에 표시된 Wi-Fi IP 주소 (예: `http://192.168.0.15:8080/`)로 동일 네트워크에 연결된 기기 어디서든 접속 가능
3. 종료할 때는 실행된 콘솔 창을 닫거나 `Ctrl + C`를 누르면 됩니다.

### 2. 인터넷에 무료 배포하여 전 세계 누구나 웹 접속 가능하게 만들기
`dist/` 폴더에 배포용 순수 정적 웹 파일(`index.html`, `css/`, `js/`)이 완전히 정리되어 있습니다. 다음 방법 중 하나로 1분 만에 전 세계 무료 공개 배포가 가능합니다:

* **Netlify Drop (가장 간편, 10초 완료)**:
  1. [Netlify Drop](https://app.netlify.com/drop) 접속
  2. `dist` 폴더 전체를 웹 브라우저 드롭존에 드래그 & 드롭
  3. 즉시 전 세계 접속 가능한 고유 URL(예: `https://prismvista-3d.netlify.app`) 발급 완료!
* **GitHub Pages**:
  1. GitHub 저장소를 생성하고 `dist/` 안의 파일들을 푸시
  2. 저장소 `Settings` -> `Pages` -> Source를 `main` 브랜치 루트로 설정
  3. `https://<사용자이름>.github.io/<저장소명>/` 주소로 즉시 서비스 제공
* **Vercel / Cloudflare Pages**:
  * `dist` 폴더를 프로젝트 루트로 지정하여 배포하면 무료 초고속 글로벌 CDN 적용

## 💻 데스크톱 프로그램으로 설치 및 실행하기

웹 브라우저 주소창이나 UI 없이 독립적인 Windows 데스크톱 소프트웨어로 사용하고 싶다면 다음 방법을 이용하십시오:

### 방법 1. 설치 파일(Setup.exe)을 통한 정식 설치
1. 루트 폴더의 **`setup.exe`** (또는 `output\PrismVista_Setup.exe`)를 실행합니다.
2. 설치 마법사를 통해 대상 경로 및 바로가기 옵션을 확인하고 설치합니다.
3. 바탕화면 및 시작메뉴에 등록된 **`PrismVista 3D`** 바로가기로 즉시 실행할 수 있습니다.
4. 삭제 시 설치 폴더의 `Uninstall.exe`를 통해 완벽히 제거 가능합니다.

### 방법 2. 무설치 포터블 직접 실행
* **`build\PrismVista.exe`**를 더블 클릭하면 설치 없이 독립 데스크톱 창(GPU 가속)으로 즉시 열립니다.

## 🎨 주요 기능 및 PrismVista 특징

### 1. 실시간 PBR 렌더링 파이프라인 (WebGL 2.0 / DXR 모델링)
* **GGX 마이크로패싯 반사 모델**: 물리 기반 렌더링(PBR)을 통해 사실적인 금속 광택과 표면 거칠기 연산
* **다중 광원 처리**: 실시간 디렉셔널 직사 태양광, 2구역 포인트 라이트, 대기 산란광(Ambient Sky) 계산
* **발광(Emissive) & 투명도(Opacity)**: 건축용 매립형 LED 조명 스트립, 네온 사인, 파노라마 커튼월 유리 투과율 지원

### 2. 환경 및 대기 조명 시뮬레이션 (Environment & Sky Atmosphere)
* **태양 고도(0°~90°) & 방위각(0°~360°) 조절**: 실시간 슬라이더 조작에 따라 태양 위치가 변경되며 그림자 방향 및 하늘색 즉각 변화
* **원클릭 날씨/대기 프리셋**:
  * ☀️ **한낮 맑음 (Midday Clear)**: 청명한 파란 하늘과 선명한 직사광선
  * 🌅 **일몰 골든아워 (Sunset Golden Hour)**: 낮게 깔리는 따뜻한 호박색 노을빛과 길게 늘어지는 드라마틱한 그림자
  * ☁️ **흐린 하늘 (Overcast)**: 부드럽고 차분한 확산광 환경
  * 🌙 **나이트 스튜디오 (Night Studio)**: 밤하늘 분위기 속 건축 조명 강조
* **원경 안개(Distance Fog)**: 대기 원근감을 살리는 지평선 안개 밀도 조절

### 3. 건축 시각화 씬 및 3D 모델링 지원 (ArchViz Scene & Model Loader)
* **내장 모던 건축 빌라 씬**:
  * 다단 콘크리트 테라스 기단 및 캔틸레버 지붕 슬래브
  * 대형 파노라마 커튼월 통유리창 및 블랙 스틸 구조 기둥
  * 반사 수면을 가진 인피니티 풀(Infinity Pool)
  * 브론즈 메탈 조각 구체 아트 오브제
  * 티크 원목 데크 및 야외 썬베드 라운지
  * 건축용 웜톤 LED 간접 조명 스트립
* **기본 3D 오브젝트 추가**: 상단 메뉴 `3D 추가 ▼`를 통해 큐브, 구, 원기둥, 바닥 슬래브 즉시 추가
* **외부 3D 파일 불러오기 (`.obj`)**: 사용자가 보유한 3D 모델 파일(.obj)을 드래그 앤 드롭하거나 `3D 파일 불러오기` 버튼으로 즉시 뷰포트에 임포트 (자동 크기 및 위치 정규화)
* **씬 계층구조 트리**: 객체 선택, 가시성 토글(👁️), 삭제(🗑️), 복제(`Ctrl+D`), 포커스(`F`)

### 4. 카메라 조작 및 건축 워크스루 네비게이션
* **마우스 조작**:
  * 좌클릭 드래그: 뷰포트 중심 궤도 회전 (Orbit)
  * 우클릭 / 휠 드래그: 화면 평행 이동 (Pan)
  * 마우스 휠: 줌 인/아웃 (Zoom)
* **키보드 건축 워크스루**:
  * `W / A / S / D`: 전진 / 좌측 / 후진 / 우측 보행 이동
  * `Q / E`: 시점 하강 / 상승
  * `Shift`: 고속 이동
  * `F`: 선택된 객체로 카메라 즉시 포커스
* **저장된 카메라 뷰 (Camera Bookmarks)**:
  * 외관 뷰, 테라스 뷰, 인테리어 뷰, 탑 뷰 등 프리셋 제공
  * 현재 시점을 새 카메라 뷰로 원클릭 저장
  * 뷰 클릭 시 자연스러운 카메라 비행 애니메이션(Smooth Glide Lerp)으로 이동
* **360° 턴테이블 모드**: 전시용 자동 카메라 회전 기능

### 5. 시네마틱 후보정 및 초고화질 렌더링 내보내기 (Tone Mapping & Export)
* **광학 및 후보정 컨트롤**:
  * 화각(FOV: 30°~95°)
  * 노출값(Exposure EV), 블룸(Bloom Glow) 하이라이트 광채
  * 대비(Contrast), 채도(Saturation)
  * 시네마틱 톤매핑: **ACES Filmic**, **Reinhard**, **Linear**
* **초고화질 렌더링 내보내기**:
  * **Full HD (1920 × 1080)**: 웹 및 일반 프레젠테이션용
  * **2K QHD (2560 × 1440)**: 고해상도 디스플레이용
  * **4K UHD (3840 × 2160)**: 건축 패널 및 고품질 인쇄용
  * `PrismVista_Render_[타임스탬프].png` 무손실 24비트 이미지로 즉시 저장

## 📁 프로젝트 폴더 구조

```
d5render/
│
├── start_web.bat                # ★ 웹 서버 1-클릭 실행 (웹 브라우저 자동 오픈)
├── start_web_server.exe         # 컴파일된 고속 내장 웹 서버 실행 파일
├── setup.exe                    # ★ Windows 데스크톱 설치 마법사
│
├── dist/                        # ★ 웹 호스팅 배포용 정적 웹 파일 (Netlify/GitHub Pages 업로드용)
│   ├── index.html               # 메인 웹 페이지
│   ├── css/style.css            # 스타일시트
│   └── js/                      # 3D 렌더러 스크립트 모듈
│
├── output/
│   └── PrismVista_Setup.exe     # 배포용 설치 마법사 패키지
│
├── build/                       # 데스크톱 빌드 결과물
│   ├── PrismVista.exe           # 데스크톱 앱 런처
│   ├── PrismVistaServer.exe     # 내장 웹 서버
│   ├── Uninstall.exe            # 제거 도구
│   └── app/                     # 렌더러 소스
│
├── src/                         # 전체 C# / WebGL 소스 코드
│   ├── app/                     # 웹 애플리케이션 코어
│   ├── launcher/                # 데스크톱 런처 소스
│   ├── installer/               # 설치/제거 소스
│   └── server/                  # 웹 서버 소스
│
└── README.md                    # 본 안내 문서
```
