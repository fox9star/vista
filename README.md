# PrismVista 3D (실시간 PBR 레이 트레이싱 & 3D 건축 시각화 렌더러)

**PrismVista 3D**는 [D5 Render](https://www.d5render.com/)의 핵심 실시간 렌더링, 태양광 및 날씨 대기 환경 시뮬레이션, PBR 머티리얼 편집, 3D 모델(OBJ) 로딩, 시네마틱 톤매핑 및 고화질 이미지 렌더링 내보내기 기능을 충실히 모사하여 개발된 독립형 3D 렌더러 소프트웨어입니다.

자연어로 3D 씬을 대화하듯 제어할 수 있는 **AI 어시스턴트(AI Copilot Chatbot)**가 내장되어 있어, 초보자도 손쉽게 자연어 명령을 통해 조명, 날씨, 3D 오브젝트 배치 및 재질을 실시간으로 조작할 수 있습니다.

## ✨ 내장 AI 챗봇 (PrismVista AI Copilot) 기능

화면 우측 하단의 **`✨ AI 어시스턴트`** 플로팅 버튼을 클릭하면 실시간 3D 제어 챗봇이 열립니다.

### 1. 자연어 3D 씬 제어 (Natural Language Commands)
자연어로 원하는 작업을 입력하면 챗봇이 인텐트를 인식하여 3D 뷰포트를 실시간으로 조작합니다:
* **날씨 및 대기 제어**:
  * *"일몰 골든아워로 바꿔줘"* ➔ 태양 고도 7° 및 따뜻한 호박색 노을 조명 즉시 적용
  * *"맑은 한낮으로 변경해줘"* ➔ 정오 맑은 하늘 및 직사광선 설정
  * *"나이트 야경으로 바꿔"* ➔ 나이트 스튜디오 및 인테리어 LED 조명 강조
  * *"흐린 날씨로 전환"* ➔ 부드러운 확산광 환경 설정
* **3D 오브젝트 생성**:
  * *"큐브 하나 추가해줘"* ➔ 뷰포트 중앙에 박스 메쉬 즉시 배치
  * *"구체 만들어줘"* ➔ 부드러운 3D 구 생성
  * *"원기둥 추가해줘"* ➔ 건축용 실린더 컬럼 배치
  * *"바닥 슬래브 추가"* ➔ 테라스 바닥 메쉬 생성
* **PBR 재질 및 컬러 실시간 변경**:
  * 객체 선택 후 *"골드 메탈 재질로 바꿔줘"* ➔ 반사율 0.95 골드 금속 재질 자동 설정
  * *"실버 크롬으로 변경"* ➔ 고광택 실버 메탈릭 설정
  * *"투명 유리로 변경"* ➔ 굴절 투명도(Opacity 0.4) 유리 재질 적용
  * *"빨간색으로 칠해줘"* / *"블루 색상으로"* ➔ Albedo 컬러 즉시 변경
* **카메라 및 애니메이션 연출**:
  * *"360도 턴테이블 회전 시작해"* ➔ 전시용 자동 카메라 회전 토글
  * *"수영장 뷰로 이동"* / *"빌라 전면 뷰"* ➔ 시네마틱 카메라 비행(Smooth Glide)
  * *"선택한 물체로 카메라 줌해줘"* ➔ 선택 객체 포커스(Focus)
  * *"고화질 렌더링 창 열어줘"* ➔ 4K 렌더링 내보내기 모달 즉각 호출
* **3D 조작 가이드 & 단축키 안내**:
  * *"단축키 알려줘"* ➔ WASD 워크스루, 마우스 조작법, PBR 이론 안내

### 2. 100% 완전 오프라인 & 외부 LLM 연동 지원
* **기본 모드**: 외부 API 키나 네트워크 없이 100% 자체 로컬 파서로 즉시 실행
* **외부 LLM 연동 (선택 사항)**: 상단 ⚙️ 설정에서 OpenAI(GPT-4o) 또는 Google Gemini API Key를 등록하여 고도화된 대화형 생성 AI로 확장 가능

## 🎨 주요 렌더러 기능 요약

1. **실시간 PBR 렌더링 파이프라인 (WebGL 2.0 / DXR 모델링)**
   * GGX 마이크로패싯 반사 모델, 금속성(Metallic), 표면 거칠기(Roughness), 발광(Emissive), 투명도(Opacity)
   * 디렉셔널 직사 태양광 + 2구역 포인트 라이트 + 앰비언트 대기광 실시간 셰이딩

2. **환경 및 대기 조명 시뮬레이션 (Sun & Sky Atmosphere)**
   * 태양 고도(0°~90°) & 방위각(0°~360°) 조절에 따른 실시간 그림자 방향 및 하늘 그라디언트 전환
   * 원경 안개(Distance Fog) 농도 제어

3. **건축 시각화 씬 및 3D 모델링 지원 (ArchViz Scene & Model Loader)**
   * 모던 건축 빌라 씬 기본 탑재 (캔틸레버 슬래브, 통유리 커튼월, 인피니티 풀, 브론즈 조각 구체, 썬베드)
   * 외부 3D 파일(`.obj`) 드래그 & 드롭 원클릭 임포트 (자동 크기 및 위치 정규화)

4. **카메라 조작 & 건축 워크스루 네비게이션**
   * 좌클릭 궤도 회전(Orbit) / 우클릭 평행이동(Pan) / 휠 줌(Zoom)
   * 키보드 건축 워크스루: `W / A / S / D` (보행 이동), `Q / E` (상하 승강), `Shift` (고속 이동)
   * `F` 키로 선택 객체 포커스, `Ctrl + D` 복제, `Del` 삭제

5. **시네마틱 후보정 & 초고화질 렌더링 내보내기 (Tone Mapping & Export)**
   * 화각(FOV), 노출(Exposure EV), 블룸(Bloom Glow), ACES Filmic 및 Reinhard 톤매핑
   * **Full HD (1920x1080)**, **2K QHD (2560x1440)**, **4K UHD (3840x2160)** 무손실 24비트 PNG 저장

## 💻 데스크톱 프로그램으로 설치 및 실행하기

* **정식 설치**: 폴더의 **`setup.exe`**를 실행하여 바탕화면 바로가기 등록 및 설치
* **무설치 포터블 실행**: **`build\PrismVista.exe`**를 더블 클릭하여 독립 창에서 즉시 실행
* **로컬 웹 서버 구동**: **`start_web.bat`**를 실행하여 브라우저에서 로컬 구동
